How I work

Plan, build, measure. Then harden.

Anyone reviewing my work should be able to see what was built, how it was checked, and what happens when something fails.

  1. 01

    Schema and API

    Plan

    I start with the data model and the API surface, then handle schema changes through migrations so the database stays reproducible.

  2. 02

    Back end and front end

    Build

    I write the back end and the interface together, one module at a time, so every feature works from the database to the screen.

  3. 03

    Tests and evaluation

    Measure

    If a feature matters, it has a test that fails when it breaks. AI features get labelled data, a held-out split and a number that has to go up.

  4. 04

    Security and fallbacks

    Harden

    I add a fallback for when an API is down, encryption for anything sensitive, and roles for anything shared.
